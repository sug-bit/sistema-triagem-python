# 🏥 Sistema de Triagem Hospitalar em Python

Projeto HealthTech desenvolvido por um Técnico de Enfermagem em transição para TI.

Sou Técnico de Enfermagem na SPDM e estudante de ADS no Centro Universitário Piaget (2026-2028). Criei esse sistema para unir minha vivência hospitalar com Python.

## Funcionalidades
- Cadastro de pacientes
- Classificação de risco (Vermelho, Amarelo, Verde)
- Fila organizada automaticamente por prioridade

## Tecnologias
- Python 3
- Lógica de programação, dicionários, listas, funções
- Conceito de Protocolo de Manchester

## Como rodar
` ```bash `
python main.py
` ``` `
